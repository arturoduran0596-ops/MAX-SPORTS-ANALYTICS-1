# MAX SPORTS ANALYTICS
Aplicación Android inicial para uso personal.

## Estado
Interfaz nativa con Fútbol, NFL, NBA, NHL y MLB. **No incluye datos en vivo ni proyecciones todavía**.

## Compilar sin computadora
Sube los archivos y carpetas a la raíz del repositorio de GitHub conservando las rutas. Ve a Actions > Build Android APK > Run workflow. Descarga el artefacto `MAX-Sports-Analytics-debug-APK`, descomprime el ZIP e instala `app-debug.apk` en Android. El APK de depuración es solo para pruebas. No almacenes claves API en el repositorio.
